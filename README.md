# SubSync
​
Fix out-of-sync subtitles in your browser. Nothing gets uploaded.
​
- Auto-sync a subtitle against a correctly-timed reference
- Or fix it manually (time shift, stretch factor, FPS conversion)
- Works with `.srt` and `.vtt`

​
[link here](https://tarawoy.github.io/subsync/)

Inspired by [sc0ty/subsync](https://github.com/sc0ty/subsync).
